## 一句话说清这个项目

现行反诈宣传是讲座、短视频、传单——用户始终在"被动接收"，听过就忘，真遇到骗局仍然中招。

本项目把角色反转：**不让 AI 当"普法老师"，让 AI 当"骗子"**。用户在安全环境里与 AI 驱动的诈骗剧本正面对抗，事后由复盘 Agent 逐句标注破绽、打分、给个性化防骗要点。

**在安全环境里被骗一次，比听十场讲座管用。**

## 三 Agent 架构

```
用户
 │
 ▼
[导演 Agent]  加载剧本 JSON，维护状态机
 │            阶段：铺垫 → 设套 → 施压 → 收网
 ▼
[骗子 Agent]  角色扮演，按人设与话术库生成回复
 │
 ▼
[复盘 Agent]  逐轮标注红旗 → 检查点评分 → 改进建议
 │
 ▼
[结果页]  得分 / 等级 / 高危漏判 / 防骗要点
```

**职责分离的理由**：调度、扮演、评估三件事分给三个 Agent，剧本扩展时只需改 JSON 不动提示词，评估标准也能独立迭代。

### 状态推进规则（按用户回应分档，不按轮次数）

| 用户回应 | 导演动作 |
|----------|----------|
| 顺从配合（答应转账、报验证码、下载软件） | 直接跳到"收网" |
| 识破或质疑（指出是诈骗、要求核实） | 跳到"施压" |
| 明确拒绝 | 跳到"施压"，累计拒绝次数 |
| 连续 2 次拒绝 | 对方失去耐心挂断 |
| 中性回应 | 按话术顺序推进 |

### 评分规则（检查点制，满分 100）

| 检查点 | 分值 | 说明 |
|--------|------|------|
| 识别话术 | 每个红旗 +20，最多 40 | 主动指出对方的诈骗手法 |
| 正确核实 | +30 | 拨打 96110 / 110、官方渠道查询、回拨原号 |
| 终止对话 | +20 | 明确挂断、拉黑，或连续拒绝逼停对方 |
| 拒绝配合 | +10 | 明确拒绝对方要求 |
| 不当配合 | 每项 -30，最多扣 60 | 转账、给验证码、下载陌生软件、共享屏幕 |

等级：0–59 需要加强 / 60–84 合格 / 85–100 优秀

## 快速开始（不用装任何东西）

用浏览器直接打开 [demo/index.html](demo/index.html)。

左侧选诈骗剧本 → 中间与"骗子"对话 → 点"结束并复盘"看评分卡。

Demo 是**单文件、零依赖**的本地模拟：剧本数据内嵌，评分由前端规则计算，不需要服务器。正式版接入 AgentArts 后，话术由知识库检索生成，复盘由大模型逐句标注。

**回归测试基准**（改动评分规则后必须复测）：

| 场景 | 期望得分 |
|------|----------|
| 全程顺从、上交验证码 | 0 |
| 只说"我打 96110 核实" | 50 |
| 连续拒绝逼停对方 | 30 |
| 识破 + 核实 + 挂断 + 拒绝 | 100 |

## 剧本库

8 个剧本，覆盖当前高发诈骗类型：

| ID | 类型 | 难度 | 目标人群 |
|----|------|------|----------|
| S01 | 冒充公检法 | ★★ | 老年人、学生 |
| S02 | 刷单返利 | ★ | 学生、宝妈、待业人群 |
| S03 | 冒充客服退款 | ★★ | 全年龄 |
| S04 | 冒充熟人借钱 | ★ | 全年龄 |
| S05 | 虚假投资理财（杀猪盘） | ★★★ | 有积蓄人群 |
| S06 | 注销校园贷 / 征信修复 | ★★ | 在校学生 |
| S07 | 虚假贷款 / 信用卡提额 | ★★ | 资金紧张人群 |
| S08 | 虚假购物（低价票 / 二手交易） | ★★ | 学生、年轻群体 |

每个剧本按以下结构存储：

```json
{
  "id": "S01",
  "type": "冒充公检法",
  "difficulty": 2,
  "persona": { "role": "自称某市公安局刑侦支队民警", "tone": "严肃、权威、逐步施压" },
  "stages": [
    { "stage": "铺垫", "goal": "建立权威身份", "lines": ["..."] }
  ],
  "red_flags": ["自称公检法并要求电话办案"],
  "correct_responses": ["挂断电话，拨打 96110 或 110 核实"]
}
```

**扩展新剧本只需加一条 JSON，不需要改代码或提示词。**

## 合规声明

**本产品仅用于反诈教育，Agent 扮演内容为模拟，不构成任何诈骗指导。**

- 全部话术基于国家反诈中心公开案例、公安部通报典型话术、公开新闻报道改写
- 已脱敏：无真实姓名、账号、金额、地区
- 不提供任何可执行的作案工具、渠道、链接或操作细节
- 不索取真实身份证号、银行卡号、验证码
